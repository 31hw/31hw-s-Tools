# 31hw's Tools

A collection of 47 tools for Windows.

## Download

Download `31hw-tools-0.1.0-setup.exe` from the [latest release](#https://github.com/31hw/31hw-s-Tools/releases/tag/v0.1.0).

## Installation

1. Download and run the installer.
2. Windows SmartScreen may show a warning because the build is not code-signed. Click **More info** and then **Run anyway**.
3. Choose an installation folder.
4. Choose whether to create desktop and Start menu shortcuts.
5. Launch 31hw's Tools.

The installer is per-user and does not require administrator privileges.

To uninstall, go to **Windows Settings → Apps** and uninstall **31hw's Tools**.

## Features

47 tools across several categories.

### Downloads
- YouTube video downloader
- Spotify song downloader
- Media downloader for links supported by yt-dlp

### Network
- Multi-Check
- RDAP / WHOIS lookup
- DNS and reverse DNS
- Email authentication checks
- Subdomain lookup
- TLS certificate inspection
- Security headers
- Redirect checker
- Wayback Machine lookup
- Favicon hashes
- CVE search
- Port checker
- DNS blocklists

### Identity
- k-anonymity password checks
- Email header analyzer
- EXIF and GPS metadata viewer
- Local image converter
- OPSEC persona generator

### Utilities
- Hashing
- Encoding and ciphers
- JWT tools
- UUID and password generators
- URL tools
- QR codes
- Timestamp converter
- Card and IBAN validation
- Permission tools

## Requirements

- Windows 10 or 11
- 64-bit
- Internet connection for online tools
